## 🚀 Overview

Prep Mind is an intelligent interview preparation platform that uses AI to provide personalized mock interviews based on your resume. Get instant feedback, track your progress, and compete with others to master your interview skills.

## ✨ Features

### 🤖 AI-Powered Resume Analysis
- **PDF Resume Upload**: Upload your resume and get personalized interview questions
- **Dynamic Question Generation**: AI generates relevant questions based on your experience and skills
- **Smart Scoring System**: Get scored (0-100) with detailed feedback on your responses

### 📊 Progress Tracking
- **Test History**: Review all your previous attempts with timestamps
- **Performance Analytics**: Identify your weak areas with detailed insights
- **Progress Monitoring**: Track your improvement over time

### 🎯 Gamified Learning
- **User Profiles**: Personalized dashboards with achievement tracking
- **Leaderboards**: Compete with other users and climb the ranks
- **Achievement System**: Unlock badges and milestones as you progress

## 🏃‍♂️ Quick Start

### Prerequisites
- Node.js (v14 or higher)
- MongoDB Atlas account or local MongoDB installation
- Google Gemini API key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Mdraza78/Prep-AI-Interview-AI-Bot-.git
   cd prep-mind
   ```

2. **Install Backend dependency**
    ```bash
   cd backend
   npm install
   ```

3. **Install Frontend dependency**
    ```bash
   cd frontend
   npm install
   ```

4. **Environment Setup**
   ```bash
    # Backend .env file
      MONGODB_URI=your_mongodb_connection_string
      GEMINI_API_KEY=your_gemini_api_key
      JWT_SECRET=your_jwt_secret
      PORT=5000
   ```

5. **Run the application**
    Start backend server (from backend directory)
        npm start

    Start frontend development server (from frontend directory)  
        npm run dev
